# Obsidian settings — recommended

After opening the vault for the first time, set these.

## Editor

- **Default new file location**: `30_inbox` (so anything created without thought lands in triage)
- **New link format**: Shortest path when possible
- **Use [[Wikilinks]]**: ON
- **Detect all file extensions**: OFF (keeps the file pane clean)
- **Strict line breaks**: OFF (markdown-standard line wrapping)

## Files & links

- **Default location for new attachments**: `_attachments` (keeps images out of entity folders)
- **Automatically update internal links**: ON

## Appearance

- Personal preference. Not load-bearing for the workflow.

## Hotkeys worth setting

- **Quick switcher** (Cmd+O): default, leave it. This is your main navigation.
- **Open graph view**: assign one. Used during graph review passes.
- **Insert template** (Templater): Cmd+Shift+T or similar.
- **Toggle pin**: useful for keeping the active design doc visible while jumping around in lore.

## Workspace setup

Recommended panes:
- Left sidebar: file explorer, search, tag pane
- Right sidebar: outline, backlinks, outgoing links
- Main: editing area (split when comparing notes)

## Sync

Out of scope for this doc. Options if needed: Obsidian Sync (paid, frictionless), iCloud (free, Mac-native, occasionally flaky with large vaults), Git (free, version-controlled, more setup). Decide based on whether you need cross-device access. Local-only is fine for solo work.
